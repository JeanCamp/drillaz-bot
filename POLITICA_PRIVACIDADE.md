# Política de Privacidade - Drillaz Bot

## 1. Coleta de Dados
O Drillaz Bot coleta apenas os seguintes dados:
- ID de usuário do Discord
- Nome de usuário do Discord
- Dados de movimentações financeiras e de itens (cofre/baú)
- Logs de operações para fins de auditoria

## 2. Armazenamento
Todos os dados são armazenados localmente em banco de dados SQLite localizado no servidor do bot.
Nenhum dado é compartilhado com terceiros.

## 3. Uso dos Dados
Os dados coletados são utilizados exclusivamente para:
- Gerenciamento de recursos da gangue
- Auditoria e controle de movimentações
- Relatórios e estatísticas

## 4. Acesso aos Dados
- Apenas membros da Alta Cúpula têm acesso a dados sensíveis
- Membros comuns têm acesso apenas aos seus próprios registros
- Todos os dados são armazenados de forma segura

## 5. Retenção de Dados
Os dados são mantidos permanentemente para fins de auditoria, exceto quando solicitada a exclusão pela administração.

## 6. Segurança
Implementamos medidas de segurança para proteger os dados, incluindo:
- Validação de permissões
- Verificação de IDs
- Logs de todas as operações

## 7. Contato
Para questões sobre privacidade, entre em contato com a administração do servidor.
